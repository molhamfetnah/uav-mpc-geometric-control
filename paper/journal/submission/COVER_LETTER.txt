WHY THIS PAPER FITS ROBOTICS AND AUTONOMOUS SYSTEMS
---------------------------------------------------
This paper presents a distributed model predictive control framework for multi-UAV quadrotor formation. The work aligns with the journal's scope in:

- Multi-robot systems and distributed control
- Autonomous navigation and formation control
- Model predictive control applications in robotics

KEY CONTRIBUTIONS
-----------------
1. Novel distributed MPC architecture for multi-UAV formation without central coordinator
2. Consensus protocol enabling decentralized coordination via ring/mesh communication
3. Comprehensive evaluation: 100% success on 7 benchmarks, 95.2% on 21 stress tests
4. Open-source implementation available on GitHub
